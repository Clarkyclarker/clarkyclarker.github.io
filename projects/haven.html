Haven: Robotic Tool Vending Machine

Overview

Haven is a secure, automated tool checkout kiosk designed for student-run makerspaces. The system was built to reduce tool loss, track tool ownership, and let users dispense and return shared shop tools without requiring constant supervision from shop staff.

My role focused on the mechatronics side of the project: translating the storage concept into a manufacturable mechanical system, integrating the gantry and rotary storage modules, and supporting full-system assembly and testing.

System Architecture

  • Storage: Six rotary tool layers hold tools in circular “cake” modules, exposing only one requested tool location at a time.
  • Delivery: A vertical Cartesian XY gantry moves between storage layers and the pickup window to handle dispense and return operations.
  • Control: A Raspberry Pi coordinates backend logic, user interaction, and system commands, while a BTT Octopus Max EZ running Klipper handles stepper motor motion.
  • Sensing: RFID identifies users and tools, while magnetic encoder feedback supports rotary position monitoring.

Mechanical Design

  • Designed and assembled the vertical Cartesian XY gantry using lead screws, linear rails, flexible couplers, pillow blocks, and custom carriage plates.
  • Selected a lead-screw-driven architecture over belt-based CoreXY because the vertical axis had to safely hold load without relying on motor holding torque or belt tension.
  • Contributed to the rotary tool cake concept, where rotating inner walls push tools between storage positions and the gantry transfer slice.
  • Supported enclosure integration using aluminum extrusion and clear polycarbonate panels for modularity, visibility, and secure tool containment.

Controls & Electronics

  • Used a centralized control architecture to simplify wiring, synchronization, and debugging compared with earlier distributed PCB concepts.
  • Integrated stepper-driven motion for the gantry and rotary storage modules through Klipper on a BTT Octopus Max EZ control board.
  • Used a Raspberry Pi 4 as the edge compute layer for backend services, system logic, and communication with the motion controller.
  • Incorporated RFID authentication, magnetic angle sensing, limit switches, power distribution, and custom PCB routing into the full electromechanical system.

Software Interface

  • Users authenticate with an RFID card and select tools through a mobile web interface.
  • The backend tracks tool inventory, user checkout status, return validation, overdue tools, and administrative controls.
  • Admin workflows include manual gantry/cake adjustment, user and tool management, system alerts, and usage visibility.
  • The software stack was containerized on the Raspberry Pi to support easier deployment, remote debugging, and faster iteration.

Testing

  • Validated the gantry through progressive subassembly tests before installing it into the full enclosure.
  • Tested the rotary tool cake with increasing tool loads to identify friction, alignment, and transfer issues.
  • Completed integrated dispense and return tests using tools with different sizes and geometries across multiple storage levels.
  • Iteratively improved reliability by addressing slice stiffness, belt/driver configuration, plate constraint, UI latency, and transfer-interface alignment.

Results & Mechatronics Takeaways

  • Delivered a working end-to-end prototype that could authenticate users, retrieve tools from storage, dispense them to a user bay, and support returns.
  • Achieved strong performance for most intended tools, with over 96% reliability for moderate-size tools and approximately 93% reliability overall during integrated testing.
  • Demonstrated that low-cost, modular makerspace tool automation is feasible at a prototype cost under the project budget.
  • Key mechatronics lesson: reliable automation depended less on any single subsystem and more on the interface between mechanics, sensing, control logic, and real user workflows.
